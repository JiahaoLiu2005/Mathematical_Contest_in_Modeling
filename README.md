## 常见模型与参考改进方法

- 聚类问题：K-means++；DBSCAN；GMM；分层聚类等。比如先用一种聚类方法得到每个类别大概的中心点，再进一步使用K-means++聚类（要求数据近似球状分布）
- 分类问题：表格赛三巨头（XGBoost、LightGBM、CatBoost）；随机森林；逻辑回归等。比如先随机森林得到特征贡献度，选取高贡献度特征训练集成树模型。又或者训练一个XGBoost，用optuna之类的去优化超参数（2025年Kaggle March Machine Learning Mania全球总冠军的方案）
- 时间序列预测问题：ARIMA；SARIMA；LSTM；GRU等。比如先训练一个模型，再用另一个模型学习前一个模型的残差
- 回归预测问题：表格赛三巨头（XGBoost、LightGBM、CatBoost）；BP神经网络；随机森林回归等。同上，比如先训练一个模型，再用另一个模型学习前一个模型的残差
- 相关性、一致性分析：皮尔逊相关性分析、斯皮尔曼相关性分析、T检验、卡方检验等。注意每种检验方法对数据的要求，离散？连续？正态分布？一般情况下，相关性分析、一致性分析和正态判据会同时出现。如果是连续数据，先上正态判据，不符合正态分布考虑数据变换或者改用Spearman相关性分析，符合正态分布的话先上T检验之类的差异性分析算法，再用Pearson相关性分析，记得都要标显著性P值
- 复杂优化问题：模拟退火；贪心算法；遗传算法等。之前我在Santa 2025圣诞树包装挑战赛用的方案是模拟退火+贪心算法+集成学习

关于模型的选择，不要太依赖AI和B站上面的思路，有很多都是有问题的。比如主包去年打了美赛C题，第一题叫我们预测奥运奖牌数量，GPT给的思路是用ARIMA，LSTM之类的时间序列算法，但是认真读题的话就会发现直接根据过去的奖牌数量去预测是有问题的。

**优化类赛题**不要乱用那些乱七八糟的动物园算法，比如什么灰狼优化算法、蜣螂优化算法。这种题目最实用的是**模拟退火算法**，打过Kaggle数据科学竞赛的同学应该知道，Kaggle每年圣诞节都会举办优化算法赛，这种比赛用的最多的就是模拟退火（我记得去年Santa 2025圣诞树包装挑战赛的全球总冠军用的方法之一就是魔改的模拟退火）

在用一个算法的时候最好先搞懂算法的底层原理和使用条件。比如Pearson相关性分析要求是连续数据，并且符合正态分布，连正态判据都没有，或者数据是离散的，直接套这个算法基本就完了。相关性分析一般会跟正态判据、显著性、差异性分析同时出现。感谢数模协会大佬的指导，祝大佬读研的时候师兄师姐发论文全部挂他共一，自己发论文全是独作（）orz

数模协会的大佬还教了我一招：美赛E题最后一问一般是写信，可以**用pyqt5做一个GUI界面放上去**，不仅好看而且显得高级（）绘图大赛是这样的（）

不要被学过的算法束缚住，有时候不一定就是那些传统算法，打开思维。比如25年的华东杯数学建模邀请赛A题，大部分人都是用那些传统算法，比如MPC啥的，去优化跳台滑雪运动员姿态，我们队不光用了传统算法，还找了跳台滑雪的比赛视频，用YOLOv8和Mediapipe对运动员做关键点检测，也就是用计算机视觉的算法分析运动员的空中姿态，差距就体现出来了（）

还有很重要的一点，**不要滥用深度学习**。举个例子：一共几百个样本做分类，上来就是一个神经网络很容易过拟合，而且据说评委也很不喜欢这种到处套神经网络的人。这种情况下简单的逻辑回归、决策树这些可能反而效果更好。数据集规模再大一点就可以尝试XGBoost, CatBoost, LightGBM这些，有些情况下集成树模型的效果可能反而优于神经网络。
